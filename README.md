# Вести — агрегатор на македонски вести (Android)

Апликација слична на time.mk: ги собира најновите вести од RSS изворите на македонските медиуми,
ги групира статиите што зборуваат за истиот настан во една „приказна“ и ги прикажува по категории.

## Структура

- `core/` — чист Kotlin (без Android), со тестови:
  - `RssParser` — RSS 2.0 и Atom (наслов, линк, опис, слика, датум, категорија)
  - `StoryClusterer` — групирање слични вести (TF‑IDF + косинусна сличност, прозорец од 36 часа)
  - `TextNormalizer` — стоп-зборови, едноставен стемер, латиница → кирилица
  - `Categorizer` — ги мапира категориите од медиумите во категориите на апликацијата
  - `BreakingNewsDetector` — кои приказни заслужуваат известување (без повторување)
  - `Sources.kt` — листа на RSS извори (лесно се додаваат нови)
- `app/` — Android апликација (Jetpack Compose, Material 3):
  - `ui/theme` — црвена бренд палета, светол и темен режим, боја по категорија (Material You по избор)
  - насловна (по 20 вести, следните се вчитуваат при скролање): датум и наслов, лепливи чипови („Сите“, „Најнови вести“ и категориите), истакната приказна со голема слика,
    компактни редови со сликичка, аватари на медиумите („Телма и уште 4“), скелет при вчитување
  - детали: голема слика со градиент, копчиња назад/сподели, картички за секој медиум (срце = омилен медиум)
  - картички на врвот: време за Скопје (Open-Meteo), курсна листа во денари (open.er-api.com), цени на горивата (`docs/fuel.json`, се ажурира по секоја одлука на РКЕ)
  - „За апликацијата“ (иконата ⓘ горе): верзија, Политика на приватност и Услови на користење (`ui/LegalTexts.kt`)
  - „Омилени медиуми“ (срцето горе десно): избор на медиуми и фид само со нивните вести, најновите први
  - последните вчитани вести се чуваат локално и се прикажуваат без интернет
  - `notify/BreakingNewsWorker` — на ~30 мин проверува и праќа известување кога 5+ медиуми пишуваат за иста вест

## Стартување

1. Отвори ја папката во Android Studio (Ladybug или понова) и почекај Gradle sync.
2. Run ▶ на емулатор или телефон (Android 8.0+).

Тестови за јадрото: `./gradlew :core:test`

## Белешки

- Користиме само RSS фидови од самите медиуми, не содржина од time.mk.
- Дел од URL-ата во `Sources.kt` не се проверени од уред; фид што не работи само се прескокнува.

## Објавување на Play Store

1. **Клуч за потпишување** (еднаш): Android Studio → Build → Generate Signed App Bundle → Create new.
   Чувај го `.jks` фајлот и лозинките на сигурно место, без нив нема ажурирања.
2. Во коренот на проектот направи `keystore.properties` (не оди на GitHub):
   ```
   storeFile=/целосна/патека/vesti-upload.jks
   storePassword=...
   keyAlias=upload
   keyPassword=...
   ```
3. `./gradlew :app:bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`.
   Пред секое ново издание зголеми `versionCode` во `app/build.gradle.kts`.
4. Политика и услови на јавен линк: GitHub → Settings → Pages → Branch `main`, папка `/docs`.
   Линкови: `https://prodanovskigjoko.github.io/vesti-android/privacy.html` и `.../terms.html`.
   По промена на `LegalTexts.kt` изврши `python3 tools/legal_pages.py` за да се обноват страниците.
